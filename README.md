# Bot sigue-línea

Robot con Arduino que sigue una línea, desarrollado con Devin.
Sitio: https://asosab.github.io/bot_sigue_linea/

## Estructura

- `firmware/` — sketches de Arduino
- `web/` — página del proyecto (Jekyll, GitHub Pages)
- `tools/` — utilidades de apoyo
- `.devin/` — configuración de Devin (MCPs, skills, permisos)

## Documentación y evidencia

Este repo es público y solo contiene código y el sitio web. El vault
Obsidian, la documentación del concurso y la evidencia con datos
personales viven en el repo privado `bot_sigue_linea-privado`
(mismo dueño, misma organización de carpetas). Los entregables en PDF
se generan desde markdown con el MCP `pdf-it`.

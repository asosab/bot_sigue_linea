# Bot sigue-línea

Robot con Arduino que sigue una línea, desarrollado con Devin.
Sitio: https://asosab.github.io/bot_sigue_linea/

## Estructura

- `firmware/` — sketches de Arduino
- `docs/` — vault Obsidian con la documentación del proyecto (`docs/index.md` es el índice)
- `web/` — página del proyecto (Jekyll, GitHub Pages)
- `.devin/` — configuración de Devin (MCPs, skills, permisos)

## Documentación

Las notas viven en `docs/` como un vault de Obsidian. Los entregables en PDF
se generan a partir de ese markdown con el MCP `pdf-it`.
